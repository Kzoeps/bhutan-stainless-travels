# Pathfinder Copy QA Checklist

Use this checklist before merging any copy updates. Every item is pass or fail.

## Core checks

- Pass if the tone is local, practical, and calm with no hype language.
- Pass if every section includes specific, concrete details such as place names, activities, or partners.
- Pass if pricing language is quote-only, uses ranges or "starting from" phrasing, and never states fixed prices.
- Pass if package tiers are described as customizable starting templates, not rigid bundles.
- Pass if the copy contains no em dash punctuation.

## Release gate

All of the following must pass before release.

### Hero

- Pass if the hero states tailor-made travel and sets a grounded promise.
- Pass if the hero avoids fixed pricing and urgency language.

### Packages

- Pass if each package is framed as a starting point with clear customization notes.
- Pass if examples are specific and do not read like generic filler.

### About

- Pass if the team or brand description includes concrete local credibility cues.
- Pass if the tone remains practical and avoids marketing superlatives.

### Contact

- Pass if the contact section requests trip details and sets expectation of a custom quote.
- Pass if the CTA avoids fixed prices and pressure language.
