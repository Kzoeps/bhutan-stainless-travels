# SEO Keyword Map and URL Architecture

## Goals

- Map core Bhutan travel intents to distinct URLs.
- Prevent keyword cannibalization by assigning ownership.
- Provide draft on-page elements per URL.

Note: Dedicated SEO subpages were intentionally removed to avoid UX/content bloat; the current IA is homepage-led.
